# Referência visual aprovada — Keise

**Status: FINAL / CANÔNICA**

A tela inicial aprovada da Keise é a referência visual armazenada em:

`assets/reference/keise-approved-home-final.webp`

Regras obrigatórias:

- `keiseApprovedHome` + `keiseApprovedTopbar` são o único dashboard visual da Keise.
- O `app-v34` e a antiga sidebar existem apenas como motor funcional invisível; nunca podem voltar a ser a tela inicial visível.
- O dashboard aprovado contém: Chat, Calendário, Nossa Rede, Teste, Supervisão, Super Pais, Meu acesso, Meu perfil e Configurações, seguido da área de Conversas.
- Abrir uma conversa não pode reconstruir, substituir ou congelar o dashboard aprovado. A conversa deve ser aberta pelo núcleo e somente depois o shell entra no modo painel.
- Novas funcionalidades devem ser integradas sobre esta referência, sem recriar uma home alternativa.

Referência aprovada pela usuária em 11/09/2026.
